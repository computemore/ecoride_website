## SEO Core Operating Principles:

1. Rendering Strategy & The App Router
Server-First Execution: Default to React Server Components (RSCs). Ship zero JavaScript to the client unless interactivity (hooks, event listeners) is strictly required. This ensures crawlers receive a fully populated DOM instantly.

Dynamic Metadata API: Utilize Next.js 14+ generateMetadata for all dynamic routes. Metadata must never be hardcoded if it relies on fetched data.

Streaming & Suspense: Implement <Suspense> boundaries with fallback UI for asynchronous data fetching to ensure the Time to First Byte (TTFB) remains extremely low, even if the primary database queries are running.

2. Strict TypeScript for SEO Entities
Type-Safe JSON-LD: Structured data (Schema.org) must be injected using standard JSON-LD scripts. All schema definitions must be strongly typed using libraries like schema-dts to prevent malformed rich snippets that Googlebot will reject.

Interface Enforcement: Create explicit TypeScript interfaces for all page-level SEO props (e.g., SeoProps { title: string; description: string; canonical: string; ogImage: string; }). The agent must not generate pages without validating against this interface.

3. Tailwind CSS & Semantic HTML
Semantic DOM Structuring: Tailwind classes must be applied to semantic HTML5 tags (<article>, <section>, <aside>, <nav>, <header>). Avoid <div> soup. Search engines weight content inside semantic tags heavily.

Cumulative Layout Shift (CLS) Mitigation: Utilize Tailwind's aspect-ratio utilities (e.g., aspect-video, aspect-square) on media containers to reserve space in the DOM before an image loads, preventing content from jumping.

Aesthetic Constraint: Maintain a lean bundle by utilizing standard Tailwind utilities. Enforce the hard-edge, minimalist UI language by systematically omitting rounded utilities (rounded-none or overriding the global theme to zero) and relying on stark color contrasts rather than heavy shadows, keeping the CSS extraction as small as possible.

4. Asset Optimization (The "Core Web Vitals" Mandate)
Next/Image Enforcement: All raster images must use next/image. The agent must configure sizes attributes explicitly for responsive breakpoints to ensure the browser downloads the smallest possible WebP/AVIF file. priority must be flagged on the LCP (Largest Contentful Paint) image above the fold.

Next/Font Optimization: Self-host all fonts using next/font/google or next/font/local. This removes external network requests to Google Fonts, entirely eliminating layout shifts associated with font-swapping.

Link Prefetching: Utilize Next.js <Link> components for all internal routing to leverage native viewport prefetching, ensuring near-instant page transitions for users and efficient crawling pathways for bots.

5. Programmatic Crawl Control
Automated Sitemaps: Generate the sitemap.xml dynamically using the sitemap.ts file convention. For parameterized routes (like user profiles or ride details), map the database output directly to the sitemap array.

Robots Management: Utilize robots.ts to explicitly block crawlers from administrative dashboards, internal API routes, and authenticated user account portals to preserve the crawl budget for public-facing acquisition pages.
