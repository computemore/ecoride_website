## [1.0.0.2] - 2026-04-20

### Added

- Added a purpose-built legal document pipeline that parses markdown headings, lists, inline emphasis, links, and document metadata into reusable website content blocks.
- Added routed legal pages for Terms and Privacy Policy under `/about/terms` and `/about/privacy-policy` with a dedicated light-surface public layout.
- Added light-tone support across the shared public shell so the header, footer, buttons, metadata, sitemap, and robots configuration treat legal pages as first-class public routes.

### Resolved

- Fixed legal list parsing so ordered and unordered lists remain grouped correctly even when the source markdown includes blank lines between items.
- Normalized the internal Privacy Policy reference used in the legal content so it points to the live website route.
- Fixed the desktop About and Explore dropdown interaction so the visual gap no longer causes the menu to close before links can be clicked.

### Validated

- `npm run lint` passes with one existing warning in `src/page-views/home-page.tsx` for the unused `homeSignalStats` symbol.
- `npm run build` passes.
- Browser verification passes for Home -> About -> Privacy Policy and Privacy Policy -> Explore -> Terms on the local dev server.

### Documentation

- Captured the legal-page rollout, shared light-tone shell updates, SEO/discovery changes, parser fixes, and dropdown interaction fix in this release note.

### Pending

- The existing unused-variable warning in `src/page-views/home-page.tsx` remains outside the scope of this change.
- Real auth flows and profile-aware public entry points remain deferred.
- Future legal copy revisions still depend on updates to the source markdown documents.

## [1.0.0.1] - 2026-04-19

### Added

- Expanded the homepage into a fuller marketing flow with clearer CTAs, route handoff cards, trust signals, and stronger local credibility framing.
- Enriched the Ride, Drive, Corporate, and About pages with more complete but still minimal storytelling, stronger section pacing, and better internal linking.
- Added a desktop corporate hero treatment using the existing `public/corporate-hero.svg` asset while keeping the heading centered and the image hidden on mobile.
- Added config-driven phase-two content for homepage signals, journey cards, rider confidence, driver support, corporate outcomes, and About overview content.
- Added link-aware marketing cards so shared content blocks can drive stronger internal navigation while staying reusable.
- Expanded the footer with social and app-download access while preserving the shared public shell.

### Resolved

- Changed the Login button text treatment to black while preserving the rounded white CTA style.
- Strengthened CTA typography across the site by making shared button text bold.
- Improved mobile spacing, section rhythm, heading scale, and footer responsiveness across the public routes.
- Aligned the corporate support CTA with the shared support email configuration.
- Fixed the `SiteTitleIcon` prop typing issue so lint can pass cleanly.

### Validated

- `npm run lint` passes.
- `npm run build` passes.
- The production build completes successfully with static generation for Home, Ride, Drive, Corporate, About, robots, and sitemap.

### Documentation

- Replaced the stale Vite-era `REACT_DEV_GUIDE.md` with Next.js App Router guidance tailored to this repository.
- Updated `CHANGELOG.md` to capture the phase-two marketing and UX refinement pass.

### Pending

- Real auth flows and profile-aware public entry points remain deferred.
- Live corporate dashboards, analytics backends, and account management workflows remain deferred.
- Rich editorial blog content, deeper enterprise workflow depth, and additional bespoke imagery remain deferred beyond the current public marketing scope.
